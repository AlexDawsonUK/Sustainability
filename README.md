# Website Sustainability
The web has a significant environmental impact. This site offers independent research and tools to help web developers build more sustainable products.

They include:
- [**WSG Report and Statement Tool**](https://websitesustainability.com/wsg-report/) (Tool, 2026)
	- Create sustainability reports, assessing websites against W3C Web Sustainability Guidelines, covering practices, compliance, standards, and transparency.
- [**Digital Sustainability Policy Guide**](https://websitesustainability.com/policy/) (Tool, 2026)
	- Explore the digital sustainability compliance and policy landscape. Filter laws, standards and guidelines (best practices) to identify relevant requirements.
- [**The Carbon Impact of Web Standards**](https://websitesustainability.com/cache/files/research23.pdf) (Research, 2023)
	- A systematic study showing how choices in HTML, CSS, media formats and other web standards affect the energy use and carbon emissions of websites.
	- Download open access [paper, data, and tests](https://websitesustainability.com/cache/files/research23.zip). 
- [**Printed**](https://printedcss.com/) (Tool, 2023)
    - A lightweight CSS library that optimises websites for printing and PDFs, helping reduce unnecessary ink, paper and resource consumption when users print web content.
- [**The Variables of Web Sustainability**](https://websitesustainability.com/cache/files/Variables.pdf) (Research, 2023)
    - A comprehensive map for understanding the many environmental, social and technical factors that influence the sustainability of a website. 

### Make A Difference

If you believe that you can help make the Internet more sustainable, please join our friendly [W3C Community Group](https://www.w3.org/groups/ig/sustainableweb/) as we're working to produce sustainability guidelines for the Web!
